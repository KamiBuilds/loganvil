# Security and publication boundary

No application code or installable release is currently distributed from this repository. Do not deploy it as a service or infer production support from progress summaries.

Public source publication is held until reproducible correctness/security blockers and deployment gates are closed and a fresh independent review passes. Source availability, beta status, release status, tested platforms and operational support will be reported separately.

Please do not put secrets, private logs, credentials or personal data in GitHub issues. A supported private vulnerability-reporting process must be established before an installable public release. No government certification or independent external audit is claimed.
