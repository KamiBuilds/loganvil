# Contributing to LogAnvil

This is presently a planning and progress repository. Suggestions about requirements, threat models, user workflows, accessibility, deployment constraints and benchmark methodology are welcome through GitHub issues.

Before proposing implementation work, check the roadmap and current publication gates. Prefer one bounded, testable vertical slice over large speculative changes. Future code changes must include observed failing regressions before fixes, complete relevant checks, documentation and an independent security/correctness review.

Do not submit credentials, private logs, real user data, proprietary assets or copied product code. Use visibly synthetic examples. Do not claim hardware, operating-system compatibility, scale or production readiness without reproducible evidence.

The project is Apache-2.0 licensed. Contributors must have rights to their contributions.
